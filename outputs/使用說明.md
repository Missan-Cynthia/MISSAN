## 已提供

- 首頁「批次加入照片」：選擇分類、選填整批尺寸，再一次多選照片；選完自動逐張建立收藏，不必填名稱、備註或逐張儲存。名稱先使用檔名，之後在圖鑑卡片按「改名稱」即可修改中文名稱。
- 批次加入會顯示成功與失敗數量，無法讀取的照片可跳過；空間不足會停止後續加入，已成功的照片保留，不會把失敗照片顯示為成功。照片自動縮至最長邊 800 像素後壓縮。
- 淺玫瑰灰粉色介面、繁體中文、手機與桌面版面。
- 使用提供的 Miss An 正式 LOGO 原圖，已內嵌於 HTML，單獨開啟亦可顯示。LOGO 下方僅標示副標「MY ARCHIVE／我的家在手裡」。app-icon.svg 仍是通用房屋安裝圖示。
- 五大分類，自訂主分類、子分類與各主分類欄位（文字、數字、日期、連結）。
- 共用童裝衣櫃六筆示範，依尺寸整理，不按哥哥弟弟分組。
- 全站搜尋、子分類／尺寸／狀態篩選、圖鑑與清單、新增／修改／刪除。
- 布料、證件、教學影片、家庭待辦等空白分類模板：新增時選對應主子分類即可填寫，亦可新增需要的欄位。
- 示範與正式資料使用獨立的本機儲存鍵。正式區初始無資料。
- JSON 匯出備份（本範例未提供匯入介面）。
- 新增或編輯資料時，可在分類下方「物品照片」選擇一張 JPG、PNG 或 WebP（原檔上限 20 MB）。預覽後按「儲存資料」，照片即顯示於圖鑑卡片；可更換或移除。照片會縮至最長邊 1000 像素並壓縮，匯出 JSON 時一併備份。
- 照片與資料共用瀏覽器有限的本機儲存空間；容量不足時會提示且不關閉編輯視窗，請先匯出備份，再減少照片。並非上傳到雲端。

## PWA

直接開啟 HTML 可使用核心介面；Service Worker 需要 localhost 或 HTTPS。
將整個資料夾放到靜態伺服器後，以支援 PWA 的瀏覽器造訪並使用瀏覽器安裝功能。首次成功載入後，Service Worker 會快取介面供離線開啟。各瀏覽器對 SVG 圖示和安裝的支援不同；正式部署建議補上 192、512 像素 PNG 圖示。本範例沒有宣稱通過各平台的安裝驗證。

## 儲存與安全

這是前端操作範本，資料存於 localStorage，未加密、不跨裝置同步。瀏覽器、網址或 HTML 檔案路徑改變時，可能讀取不同儲存區；清除網站資料會遺失內容，請先匯出。

勿填入真實身分證字號、證件影像或其他敏感資料。證件模板只供測試類型、保管位置、到期日等欄位；照片功能僅供一般物品使用。

正式版本應採用伺服器資料庫、登入與家庭成員權限、定期備份及存取稽核。證件使用私有檔案儲存、TLS 傳輸加密、靜態加密及受控金鑰、短效授權連結。不要把金鑰放在前端 HTML 裡。
